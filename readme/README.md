# Documentation & Reports

All project **reports**, **technical write-ups**, and **standalone README-style documentation** belong in this folder only. Do not add equivalent files at the repository root or scattered under `backend/` / `frontend/` unless they are code-adjacent API docs tied to a specific module.

## Contents

| Document | Description |
|----------|-------------|
| [BREAK_EXTENSION_REPORT.md](./BREAK_EXTENSION_REPORT.md) | Break time extension, break types, and login/logout time behavior |
| [TEA_BREAK_DESKTOP_NOTIFICATION_DIAGNOSIS.md](./TEA_BREAK_DESKTOP_NOTIFICATION_DIAGNOSIS.md) | User-side diagnosis of tea break desktop (browser/OS) notifications |

## Adding new documents

1. Create the file in this folder (`readme/`).
2. Add a row to the table above.
3. Use descriptive `SCREAMING_SNAKE` or `kebab-case` filenames (e.g. `AUTH_FLOW_REPORT.md`).
