# Intelligent Holiday Engine - Technical Specification

## 🎯 Executive Summary

Transform the Holiday Management system into an intelligent, semi-automated governance system with:
- 3-layer calculation engine (Fixed, Lunar, Manual)
- Internal company-controlled holiday dataset
- Smart year cloning with preview
- Manual override with audit trail
- Automatic attendance synchronization

---

## 🏗️ System Architecture

### Layer 1: Fixed Date Engine
Handles holidays with fixed dates (e.g., Republic Day - Jan 26)
- Date remains constant
- Weekday recalculated annually
- Examples: Republic Day, Independence Day, Christmas

### Layer 2: Indian Lunar Engine
Handles lunar-based holidays (e.g., Diwali, Holi)
- Date changes annually
- Fetched from Internal Holiday Dataset
- Weekday calculated from dataset date
- Examples: Diwali, Holi, Ganesh Chaturthi

### Layer 3: Manual Override Layer
Allows admin customization
- Edit auto-generated holidays
- Override calculated dates
- Lock holidays from changes
- Full audit trail

## 🔄 API Endpoints

### Dataset Management
- `POST /api/admin/holiday-dataset/upload` - Upload dataset
- `GET /api/admin/holiday-dataset?year={year}` - Get dataset for year
- `GET /api/admin/holiday-dataset/status?year={year}` - Check dataset completeness
- `DELETE /api/admin/holiday-dataset/:id` - Delete dataset entry

### Clone Operations
- `POST /api/admin/leave-years/:id/clone/preview` - Generate clone preview
- `POST /api/admin/leave-years/:id/clone/confirm` - Confirm and save clone
- `GET /api/admin/leave-years/:id/clone-history` - Get clone history

### Manual Override
- `PUT /api/admin/holidays/:id/override` - Apply manual override
- `GET /api/admin/holidays/:id/history` - Get edit history

## 🔐 Security & Validation

### Validation Rules:
1. Prevent duplicate dates within same year
2. Warn if two holidays fall on same day
3. Prevent deletion of locked holidays
4. Prevent activating year with missing dataset holidays
5. Require admin/HR role for all operations
6. Log all dataset uploads and clones

### Error Handling:
1. Dataset missing → Show warning, prevent clone
2. Invalid date format → Reject upload
3. Duplicate holiday code+year → Reject or update
4. Clone failure → Rollback, show error
5. Attendance recalc failure → Queue for retry
