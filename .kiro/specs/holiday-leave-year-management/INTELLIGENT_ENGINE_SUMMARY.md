## 🏗️ System Architecture

### 3-Layer Intelligence Engine

**Layer 1: Fixed Date Engine**
- Handles holidays with fixed dates (Republic Day, Christmas, etc.)
- Recalculates weekday for target year
- Preserves month and date

**Layer 2: Indian Lunar Engine**
- Handles lunar-based holidays (Diwali, Holi, etc.)
- Fetches dates from Internal Holiday Dataset
- Calculates weekday from dataset date
- Flags missing dataset entries

**Layer 3: Manual Override Layer**
- Allows admin customization
- Full audit trail
- Lock mechanism
- Edit history tracking

## 🔄 How It Works

### Clone Flow:
```
1. Admin clicks "Clone Year"
2. System generates preview:
   - Fixed holidays → Recalculated
   - Lunar holidays → Fetched from dataset
   - Manual holidays → Flagged for review
3. Admin reviews and edits preview
4. Admin confirms
5. Holidays created in target year
6. Attendance automatically recalculated
```

### Dataset Upload Flow:
```
1. Admin uploads Excel file
2. System validates:
   - Required columns present
   - Date formats correct
   - No duplicates
3. System shows validation results
4. Admin confirms
5. Dataset stored with version number
6. Available for cloning
```

### Manual Override Flow:
```
1. Admin edits holiday
2. System records:
   - Old value
   - New value
   - Admin ID
   - Timestamp
3. Holiday marked as manually edited
4. Attendance recalculated
5. Change logged in audit trail
```

## 📊 Example Holiday Configurations

### Fixed Holiday (Republic Day):
```javascript
{
    name: "Republic Day",
    calculationType: "FIXED",
    baseMonth: 1,
    baseDate: 26,
    type: "National",
    isAutoGenerated: true
}
// Clones to: Jan 26, 2026 (Thursday)
```

### Lunar Holiday (Diwali):
```javascript
{
    name: "Diwali",
    calculationType: "LUNAR",
    indianHolidayCode: "DIWALI",
    type: "National",
    isAutoGenerated: true,
    sourceDatasetVersion: "v1"
}
// Fetches from dataset: Nov 8, 2026 (Sunday)
```

### Manual Holiday:
```javascript
{
    name: "Company Foundation Day",
    calculationType: "MANUAL",
    type: "Company",
    isAutoGenerated: false,
    isManuallyEdited: true
}
// Requires admin review when cloning
```
